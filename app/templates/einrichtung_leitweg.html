Leitweg-ID einrichten

← Zur Konfiguration

Worum es geht

Eine Leitweg-ID ist die Zustelladresse einer Behörde. Ohne sie nimmt keine Behörde eine Rechnung an. Sie gehört an die Firmenkartei des Kunden — dort, wo auch Anschrift und USt-IdNr. stehen.

OPERA hat dafür kein eigenes Feld. Es gibt aber benutzerdefinierte Felder, die jedes Haus selbst beschriften kann. Auf dieser Seite legen Sie fest, welches davon Ihr Haus für die Leitweg-ID benutzt.

Der Weg über „Mitgliedschaften" funktioniert nicht. OPERA bietet Mitgliedschaften nur an der Gastkartei an, nicht an der Firmenkartei. Wer es dort versucht, findet die Karteikarte nicht — und genau deshalb ist der in OPERA vorhandene Typ „LEITWEG" nie benutzt worden.

Schritt 2: Das Feld in OPERA sichtbar machen

Einmal pro Haus. Danach kann der Empfang die Leitweg-ID an der Firmenkartei eintragen wie eine Telefonnummer.

  1. In OPERA anmelden mit einem Benutzer, der die Bildschirmmasken ändern darf. Wenn Sie nicht wissen, ob Sie das dürfen: Sie merken es in Schritt 3 — der Menüpunkt fehlt dann einfach.
  2. Eine Firmenkartei öffnen. Menü Kundenkontakt → Profile, dann eine Firma suchen und öffnen. Wichtig: eine Firma, keinen Gast — die Maske heißt intern ACC_MAIN.
  3. Den Screen Painter aufrufen. Bei geöffneter Kartei im Menü Setup → Screen Painter (je nach Version Konfiguration → Bildschirmgestaltung). OPERA legt eine Bearbeitungsansicht über die Maske.
  4. Das Feld aus der Liste holen. In der Liste der verfügbaren Felder das in Schritt 1 ermittelte suchen — zum Beispiel UDFC05 — und in einen freien Bereich der Maske ziehen.
  5. Beschriften. Als Bezeichnung Leitweg-ID eintragen. Genau so, ohne Zusätze: Danach sucht der Empfang.
  6. Länge prüfen. Das Eingabefeld muss 46 Zeichen aufnehmen können. Ist es kürzer eingestellt, werden längere Leitweg-IDs beim Tippen abgeschnitten — und das fällt niemandem auf.
  7. Speichern und schließen. Danach eine Firmenkartei neu öffnen: Das Feld muss sichtbar sein.
Der häufigste Fehler: Das Feld wird an der Gastkartei eingerichtet statt an der Firmenkartei. Es ist dann da, aber nicht dort, wo eine Behörde als Rechnungsempfänger steht. Die Probe: Öffnen Sie eine Firma — sehen Sie das Feld dort, ist es richtig.

Woran Sie merken, dass es wirkt

Tragen Sie an einer Firmenkartei mit Behördenbezug eine Leitweg-ID ein, lesen Sie die Rechnungen neu ein und öffnen eine Rechnung dieses Kunden. Unter Käuferreferenz muss dann die Leitweg-ID stehen, und daneben „Leitweg-ID" als Herkunft — nicht „Ersatzwert".

Steht dort etwas anderes als eine Leitweg-ID, sagt die Anwendung es in der Prüfung und benutzt den Wert nicht. Eine Leitweg-ID hat einen festen Aufbau (Ziffern, Bindestrich, zweistellige Prüfziffer); was nicht so aussieht, geht nicht als Behördenadresse hinaus.
